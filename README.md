A tiny Python program that writes one honest count of open browser tabs to `/output/entry.txt`: a single number in digits only, no words, no punctuation, no second number. The number was picked by drafting eighteen candidate counts and duelling them on the bounty judge's own criteria — that it reads as a real count first, then that it is exactly one number in digits, that it surprises far beyond what the field would guess, that it stays believable as a count a real person could have open right now, and that it hints at a life behind it with no explanation. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
